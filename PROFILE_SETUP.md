# Profile README Setup Guide

This guide explains how the `Kira2168/Kira2168` profile README works and how to customize it.

---

## How the Profile README Works

GitHub automatically shows `README.md` from a repository named **exactly the same as your username** (`Kira2168/Kira2168`) at the top of your profile page (`github.com/Kira2168`).

---

## Customizing the README

| Section | How to Edit |
|:---|:---|
| **Header banner** | Change the `text=` value in the capsule-render URL |
| **Typing animation** | Edit the `lines=` values in the readme-typing-svg URL |
| **Portfolio badge** | Update the `href` link to your portfolio URL |
| **Projects table** | Add or remove rows; update repo links as needed |
| **Skill icons** | Edit the `i=` list at `skillicons.dev/icons` |
| **Social badges** | Update the `href` links to your social profiles |

---

## Contribution Graph

GitHub always shows a **contribution graph** below your profile README. You **cannot** hide it through the README itself.

### To reduce what shows:
1. Go to your profile and click **Edit profile**
2. Toggle off **"Include private contributions on my profile"**

### To hide the graph entirely:
1. Go to **Settings → Public profile**
2. Enable **"Make profile private and hide activity"**

> ⚠️ Note: Making your profile private hides it from all other users.
